# BigData Exam Simulator (빅데이터 분석기사 실기 시험 시뮬레이터)

한국데이터산업진흥원(K-Data) 주관 **빅데이터 분석기사 실기 시험** 대비 인터랙티브 웹 시뮬레이터 애플리케이션입니다.

---

## 🌟 주요 기능

1. **실전 모의고사 100점 통합 풀코스 (180분 타이머)**:
   - 제1유형(30점) + 제2유형(40점) + 제3유형(30점) = 100점 만점
   - 실시간 카운트다운 타이머 (일시정지/리셋)
   - 60점 이상 합격 판정 배지 및 종합 성적표(Scorecard) 발급

2. **작업형 제1유형 실습실 (데이터 전처리 & 연산)**:
   - 결측치 중앙값 대체, 사분위수(IQR) 이상치 탐지, 시계열 날짜 파싱 등 빈출 기출 문제 수록
   - 파이썬 내장 에디터, 표준출력(stdout) 캡처 및 부동소수점 오차 허용 자동 채점
   - 모범 답안 및 힌트 탭 제공

3. **작업형 제2유형 머신러닝 파이프라인 검증기**:
   - `X_train`, `y_train`, `X_test` 제공 환경에서 전처리 -> 모델링 -> `result.csv` 제출
   - 숨겨진 평가 데이터셋(`y_test`)을 바탕으로 실시간 **ROC-AUC** 점수 산출 및 40점 환산 채점
   - 파일 누락, 행 수 불일치, 결측치(NaN/Inf), 인덱스 누락 방지 검증기

4. **작업형 제3유형 통계적 가설검정 시뮬레이터**:
   - 대응표본 t-검정, 독립표본 t-검정(Levene 등분산성 연계), 일원배치 분산분석(ANOVA), 카이제곱 독립성 검정
   - 소문항별 단계적 답안 작성(검정통계량, p-value, 귀무가설 기각 판정)
   - `scipy.stats` 및 `statsmodels` 파이썬 계산기 내장

5. **시험장 핵심 치트시트 & 성적 대시보드**:
   - 인터넷 검색이 불가능한 시험장 환경 대비 `dir()`, `help()`, 판다스/사이킷런/통계 치트시트
   - 응시 이력 저장(`history/exam_history.json`), 회차별 점수 추이 차트 및 취약점 진단
